# Prepwise

An interview preparation portal for Khushi Sharma, built with React and Vite. Progress, quiz attempts, and bookmarks are saved in this browser with localStorage. This demo has no server-side account or authentication.

## Run locally

1. Install Node.js (version 20.19+ or 22.12+).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. To create a production build, run `npm run build`.

## Included

- Dashboard and topic progress
- Searchable, filterable interview question bank
- Short timed quiz with saved results
- Mock interview practice
- Progress analytics and weak-topic recommendations
- Bookmarks and editable profile

All sample questions and scores are local demo data. Clearing site storage resets saved progress.
